# 多平台链接转文字

用户给出一个或多个媒体链接，希望获取逐字稿、字幕或本地内容归档时使用。若任务明确是小红书博主全量归档、X / B 站单条视频或播客进飞书，优先选择对应的专用 Skill。

## 默认交付

每个链接单独建立结果目录，并生成：

- `transcript.md`：原语言逐字稿。
- `subtitles.srt`：带时间戳字幕。
- `metadata.json` 使用统一字段：`title`、`platform`、`source_url`、`creator`、`published_at`、`duration_seconds`、`language`、`engines`。未知字段设为 `null`。

多条链接按输入顺序处理，结果分别保存在各自目录；某条失败时继续处理其他链接，最后给出成功与失败清单。

## 执行方式

开始处理前检查本 Skill 需要的本机工具；缺少时运行本目录下的 scripts/setup.sh，完成后继续，不要求用户手动配置模型。

1. 先判断链接对应视频、音频还是图文内容。使用 yt-dlp 支持的站点解析媒体；网页文章或笔记正文使用 Crawl4AI 读取。
2. 音视频优先使用本地 MLX Whisper；不可用时用 faster-whisper。若缺少运行组件，使用现有包管理器准备本地环境后继续；不要把完整媒体发给云端转写服务。
3. 图文内容提取正文；图片执行 OCR。对用户给的一批链接，不要求用户拆成多次发送。
4. 保留原语言和说话顺序，逐字稿添加自然标点。只有用户提出时才额外生成摘要、分镜或二次创作。
5. 输出到当前项目的“转写结果”目录，每条链接一个子目录，按标题命名；完成后汇报处理条数和结果目录。

遇到平台需要登录、付费或链接失效时，说明是哪一条无法读取，并继续处理其他链接。不要编造成功结果。

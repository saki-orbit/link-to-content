# 播客精华沉淀到飞书

用户给出播客单集链接，希望得到文字稿、精华或飞书文档时使用。默认一次完成“听取内容—整理—形成可回看的文档”。

## 默认交付

本地标准素材与飞书文档包含：

1. `transcript.md`：清理口头填充词后的完整文字稿，保留事实、观点和语气。
2. `subtitles.srt`：带时间戳字幕。
3. `metadata.json` 使用统一字段：`title`、`platform`、`source_url`、`creator`、`published_at`、`duration_seconds`、`language`、`engines`。未知字段设为 `null`。
4. 飞书文档：结构化精华、重要观点的时间戳和 Mermaid 思维导图。

## 执行方式

开始处理前检查本 Skill 需要的本机工具；缺少时运行本目录下的 scripts/setup.sh，完成后继续，不要求用户手动配置模型。

1. 从单集网页解析音频地址并下载音频；小宇宙链接优先尝试本机 Crawl4AI 和媒体解析工具。无需用户自己找音频文件。
2. 使用本地 Whisper 模型生成原始逐字稿，保留时间戳。只有文字进入后续整理，避免把长音频交给云端转写服务。
3. 删除“嗯、啊、然后”等不承载意思的口头填充词，但不能删掉观点、限定条件、例子或说话人的立场。不要把精简稿伪装成逐字稿。
4. 按“核心观点—论据—案例—启发”组织精华；摘要中的事实和引用必须能在逐字稿中找到。
5. 用户要求沉淀到飞书时，使用当前 DeepSeek Harness 可用的飞书连接创建文档并写入内容。若没有可用的飞书写入工具，先生成排版好的 Markdown 文件和思维导图，不假装已写入飞书。
6. 完成后回传文档链接；若生成了本地文件，同时给出文件位置。
